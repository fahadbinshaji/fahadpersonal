# Fahad Bin Shaji | Environmental Engineer Portfolio

A responsive, static portfolio website focused on ocean and beach management, marine environmental monitoring, ecological assessment, and environmental compliance across the UAE.

## Files
- `index.html` - page structure and portfolio content
- `styles.css` - responsive styling and nature-inspired visual design
- `script.js` - mobile navigation and dynamic footer year
- `fahad-profile.png` - profile photo supplied for the portfolio

## Run locally
Open `index.html` in a browser. No package installation or build step is required.

## Deploy with GitHub and Vercel
1. Create a GitHub repository and upload all files in this folder to the repository root.
2. In Vercel, select **Add New Project** and import the repository.
3. Use the **Other** framework preset, leave build command and output directory empty, and deploy.
4. Ensure `fahad-profile.png` is committed in the same directory as `index.html`.

Vercel will redeploy automatically when you push future changes to the connected Git repository.
