# Fahad Bin Shaji Portfolio

Responsive static portfolio for Fahad Bin Shaji, Environmental Engineer specialising in ocean and beach management.

## Files
All required image assets are included in this folder, including the full-site coastal background, profile photograph, five client logos, and two award photographs. Keep the files together in the same folder. No need to upload images separately one by one: upload the entire folder contents to your GitHub repository, or upload this ZIP to a repository after extracting it.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload all files inside `fahad-portfolio` to the root of a GitHub repository.
3. Import the repository at https://vercel.com/new.
4. Use the Other / static site preset. No build command is required.

## Local preview
Open `index.html` in a browser. For best results, use a simple local static server.
