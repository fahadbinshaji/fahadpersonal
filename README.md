# Fahad Bin Shaji Portfolio

A responsive, static portfolio website for Fahad Bin Shaji, Senior Environmental Engineer. Built with plain HTML, CSS, and JavaScript, so it does not need a build step or framework dependencies.

## Preview locally

Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub and Vercel

1. Create a new GitHub repository, for example `fahad-bin-shaji-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
4. As this is a static site, no build command is needed. Use the repository root as the project root and leave the output directory empty/default.
5. Vercel will provide a URL. You can add a custom domain in the project settings if needed.

## Before publishing

- Confirm the phone number, email, LinkedIn URL, award names, project descriptions, and dates.
- The portfolio intentionally uses high-level project descriptions and does not publish confidential reports or technical client data.
- The site currently uses Google Fonts, so the typography requires an internet connection. System fallbacks are included.
